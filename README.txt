HOW TO PUBLISH FREE ON NETLIFY
1. Go to https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the entire website folder onto the upload area.
4. Netlify will publish it and provide a free *.netlify.app address.
5. To update the site, edit the files and upload the updated folder again.
For a more permanent workflow, connect the folder to a GitHub repository and let Netlify deploy automatically whenever you push changes.

HOW TO PUBLISH FREE ON GITHUB PAGES
1. Create a public GitHub repository.
2. Upload the contents of this folder.
3. Open Settings > Pages.
4. Select Deploy from branch and choose the main branch.
5. GitHub will provide a free *.github.io address.
